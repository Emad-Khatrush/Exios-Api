# الحسابات الإضافية وربطها — Local

أضيفت 98 حسابًا ومجموعة إلى قاعدة Local `exios-prod-copy`. الشجرة أصبحت 232 حسابًا ومجموعة بدل 134. عدد القيود قبل تجهيز الحسابات وبعده 21,492؛ لم يولّد التجهيز قيدًا ماليًا ولم يغيّر الأرصدة السابقة.

## أماكن الاستخدام

| العمل | المكان |
|---|---|
| عرض الحسابات أو تجهيزها على قاعدة أخرى | المحاسبة ← شجرة الحسابات ← تجهيز الحسابات الإضافية |
| حوالة خاطئة واستردادها | المحاسبة ← التسويات والمستحقات ← عملية جديدة ← حوالة خاطئة |
| تحويل خرج ولم يصل بعد | التسويات والمستحقات ← تحويل بين الحسابات بانتظار الوصول |
| تأمين مكتب أو مخزن | التسويات والمستحقات ← تأمين مسترد |
| راتب أو عمولة مستحقة ثم صرفها جزئيًا أو كاملًا | الموظفون والرواتب ← مستحقات الرواتب والعمولات |
| بيع مخزون الشركة | التسويات والمستحقات ← بضاعة الشركة ← بيع |
| شراء مخزون الشركة من المورد مع السداد لاحقًا | فاتورة مورد جديدة ← يُحمّل على مخزون الشركة ← الكمية والمكتب وتأكيد الملكية |
| ضرائب ليبيا وتركيا | المصروفات السريعة أو فاتورة المورد ← مصروف ضرائب - ليبيا أو تركيا |
| مخصص ذمم العميل أو انخفاض المخزون | التسويات والمستحقات ← نوع المخصص؛ تخفيضه من العملية الأصلية |
| تسجيل قرض طويل الأجل أو سداد أقساطه | رأس المال والقروض ← حساب القرض |
| نقل الأقساط المستحقة خلال سنة | التسويات والمستحقات ← نقل أقساط قرض إلى المستحق خلال سنة |
| فرق إعادة تقييم حساب نقدي بعملة أجنبية | التسويات والمستحقات ← فرق إعادة تقييم عملة؛ أدخل الفرق بالدولار |
| بيع طرد متروك وتسجيل تكلفة شحنه | الطلبية الأصلية ← المحاسبة ← طرود لم تُستلم ← إعلان متروك ← بيع |

## مثال الحوالة الخاطئة

1. سجل الخروج 4,260.98 يوان من Alipay كحوالة خاطئة، مع التاريخ والمكتب والبيان ورقم عملية الكشف إن وجد.
2. عند رجوع 4,260 يوان، افتح العملية واضغط تسوية وسجل الاستلام في حساب Alipay.
3. يتبقى 0.98 يوان. إذا تأكد أنه لن يُسترد، اختر شطب مبلغ لن يُسترد واكتب السبب.
4. أصل الحوالة والاسترداد يتحركان عبر حساب مستحق، والفرق المشطوب فقط يدخل المصروف.
5. إذا استوردت الكشف، طابق الخروج مع قيده الموجود. لسطر الرجوع، اختر «تسوية حوالة أو تأمين أو مستحق مسجل»، ثم اختر العملية الأصلية. هذا يسجل التسوية ويربط السطر بها في معاملة واحدة.

إذا كان الرجوع مسجلًا سابقًا، استخدم مطابقة القيد الموجود؛ لا تضف تسوية ثانية.

## الرواتب والعمولات

- تسجيل الاستحقاق يسجل المصروف والالتزام، والصرف يسدد الالتزام فقط.
- يحتفظ كل استحقاق بالموظف والشهر والعملة، ويظهر مع دفعاته والمتبقي في تفاصيل الموظف.
- استحقاق الراتب يسمح بخصم جزء من السلفة المتاحة، ويظهر المستحق للصرف بعد هذا الخصم. خصم السلفة يسوي حسابها عند تسجيل الاستحقاق، فلا يتكرر عند الصرف.
- الاستحقاقات مدخلات صريحة؛ مبلغ الاستحقاق يكتبه المحاسب. هذا المسار لا ينقل تلقائيًا الخصومات والعمولات الموجودة في نموذج الراتب إلى الاستحقاق.
- عند وجود استحقاق راتب أو عمولة لهذا الشهر، يجب تسويته من هذا المسار حتى لا يصرف الشهر مرة أخرى من نموذج الراتب العادي.
- نموذج الراتب المعتاد لا يزال يعمل للموظفين دون استحقاقات مسجلة؛ العمولات فيه تُحمّل على حساب عمولات الموظفين مستقلًا عن الراتب.

## المخزون والبضائع المتروكة

مخزون الشركة مخصص لبضائع تملكها الشركة وتُشترى للبيع. شراء المخزون يرفع الأصل، وعند بيع كمية منه تُسجل الإيرادات وتخرج تكلفة تلك الكمية. آخر كمية تحمل المتبقي من التكلفة لتجنب فروق التقريب. لكل بند فاتورة مورد سجل بضاعة مرتبط بها، وسداد المورد يستخدم نظام الدفعات المعتاد.

المسار الجديد يدعم الشراء والبيع النقدي للكمية، ولا يدعم حاليًا مرتجع مخزون للمورد عبر الإشعار الدائن. لا تُسجل المرتجعات كمصروف؛ يلزم تسوية الكمية والتكلفة مع المورد.

البضائع المتروكة ذات تكلفة شحن سابقة تُباع من الطلبية الأصلية. لا تعِد تسجيل تكلفة الشحن في مخزون الشركة أو كمصروف جديد.

## المصروفات والتقارير

- فصلت الكهرباء والمياه، الهاتف، الإنترنت، الوقود، صيانة السيارات، صيانة المكاتب، القرطاسية، رسوم البنوك ورسوم التحويل.
- الضرائب مصروفات مدخلة صراحة لليبيا وتركيا؛ لا يوجد حساب تلقائي لنسب الضرائب أو VAT.
- جرد الخزينة الجديد يوجه العجز إلى مصروف العجز والزيادة إلى إيراد الزيادة. القيود السابقة بقيت على حساباتها.
- فروق التسويات الجديدة تُفصل إلى أرباح وخسائر صرف محققة، وفروق إعادة التقييم تُسجل مستقلة. التقرير يجمع الحسابات الجديدة والحساب القديم.
- الإهلاك الجديد موزع بين السيارات والمعدات والأجهزة، وبيع الأصل يعكس مجمعات الإهلاك المستخدمة فعلًا في قيوده السابقة والجديدة.
- الحسابات الجديدة للأصول والالتزامات لها تصنيفات افتراضية في التحليل المالي. راجع تصنيف التأمينات والقروض بحسب تاريخ استردادها واستحقاقها من إعدادات التحليل المالي.
- شطب فرق حوالة أو تأمين يتطلب سببًا. تخفيض المخصص لا يغيّر دين العميل أو رصيد محفظته.

## الإلغاء والمطابقة

الإلغاء يعكس القيود ويحتفظ بالسجل؛ العملية ذات تسويات أو مبيعات لا تُلغى قبل إلغاء هذه الحركات. بيع مخزون من فاتورة يمنع إلغاء فاتورته حتى إلغاء البيع. إلغاء تسوية يعيد المتبقي ويحرر ربط الكشف. تسوية أُنشئت من سطر كشف يمكن إلغاؤها من السطر أو من قائمة التسويات، ويتعامل معها زر إعادة التجربة في Local.

مطابقة التسويات الجديدة من الكشف بتاريخ قبل الجرد موقوفة برسالة توجه لمراجعة الرصيد الافتتاحي والتسوية التاريخية حتى لا تتكرر حركة النقد.
